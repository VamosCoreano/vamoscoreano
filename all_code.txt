          <h2>¿Por qué existe Vamos Coreano?</h2>
          <p class="big rv">Hola, soy Hyunho Lee.</p>

          <span class="kicker rv">La historia</span>
          <p class="rv">Estudié Literatura Coreana y hoy soy instructor oficial certificado. Pero lo que me llevó a crear este proyecto fue ver, una y otra vez, cómo los hispanohablantes aprendían coreano por el camino más difícil.</p>
          <p class="rv">Casi todo el material disponible pasa por el inglés, y se nota: explicaciones traducidas dos veces, ejemplos poco naturales y un aprendizaje que nunca termina de conectar con tu forma de pensar. Por eso diseñé un método directo, del español al coreano, pensado para la mente hispanohablante.</p>

          <span class="kicker rv">El enemigo</span>
          <ul class="enemy rv">
            <li><span><strong>Materiales traducidos del inglés.</strong> Textos con sabor a traducción automática que confunden más de lo que explican.</span></li>
            <li><span><strong>La romanización.</strong> Letras latinas que arruinan tu pronunciación desde el primer día.</span></li>
            <li><span><strong>Memorizar sin entender.</strong> Reglas sueltas, sin principio ni contexto, que se olvidan en una semana.</span></li>
          </ul>

# [VAMOS COREANO: BRAND & WEB BLUEPRINT v1.0 - 2026.10]

## Principios de Diseño
### 1. One Action, One Screen
En una pantalla, no hables de dos cosas a la vez. Mantén un solo objetivo claro por sección(pantalla)
### 2. White Space (Espacio en blanco)
No llenes la pantalla con demasiado texto. Deja que el diseño respire para guiar la atención del usuario.
### 3. Micro-interactions
Cada detalle importa. Un sutil efecto de glow, fade, textura y movimiento fluido hace que la página se sienta premium.
### 4. Restricción de color
Para mantener la consistencia visual, utilizaremos estrictamente solo 4 colores en toda la página:
• Blanco (Fondo base/cremoso) - #F8FAFC
• Negro (Texto principal) - #0F172A
• Azul (Color de marca) - #2563EB
• Naranja (Acento/Botones) - #F97316
### 5. Jerarquía Tipográfica
2 tipografías
  Bricolage Grotesque
  Pretendard
Define 6 tamaños exactos
  hero-impact: 5rem
  hero: 3rem
  title: 2rem
  subtitle: 1.25rem
  body: 1rem
  micro: 0.875rem
### 6.  Reutilización de Componentes
Nunca inventes un diseño nuevo para cada página. Crea un "kit básico" (botón principal, tarjeta de curso) en css y úsalo como piezas de Lego.(como coreano jaja)
### 7. Tono y Voz
Todos los mandatos deben dirigirse de "tú". Los botones siempre deben comenzar con un verbo de acción directa. Y siempre no soy yo. SOMOS NOSOTROS.
E.j.:
⁠Descubre el curso⁠ (O)
⁠Enviar⁠ (X) ➔ Envía (O)
⁠Únete a la comunidad⁠ (O).
Conocer (X) -> conoce (O) 
// *QUe hago con sobre mi… (Sobre nosotros es muy largo :v)
### 8. Sistema de Espaciado 8pt
Regla: Todos los márgenes y paddings deben ser múltiplos de 8 (8px, 16px, 24px, 32px, 48px, 64px).

## VAMOS COREANO : BRAND
### 0. We Are (우리의 정의)
VAMOS COREANO es una plataforma y marca que ofrece contenidos educativos de coreano y una comunidad, diseñados a la medida para hispanohablantes. 
### 1. La Misión
Nuestra misión es guiar a los hispanohablantes a dominar el coreano de la forma más rápida y precisa, sin pasar por el filtro innecesario del "inglés" 
### 2. ¿Por qué nosotros?
No somos otra simple plataforma de cursos de coreano. Un tutor optimizado exclusivamente para hispanohablantes, que combina su especialidad en Literatura Coreana, certificación oficial y una comprensión absoluta del mundo hispano, diseña y lidera este camino. 
### 3. El Enemigo
Materiales mal traducidos con IA a través del inglés, la dependencia de la romanización que arruina la pronunciación, y la educación aburrida que obliga a memorizar sin explicar los principios ni el contexto. 
### 4. Valores Centrales
 Claridad Extrema : Que ningún principiante se pregunte "¿Qué debo hacer aquí?" ni por 0.1 segundos. Diseñaremos la educación, la web y el UX/UI de la comunidad de manera abrumadoramente sistemática e intuitiva. 
 Valor Real : No seremos una marca vacía que solo persigue dinero. Jamás haremos compromisos estúpidos que ensucien la página o interrumpan la inmersión del estudiante solo por ganar unos dólares (como poner anuncios innecesarios). 
### 5. Slogan
Un idioma. Un objetivo. 100% para hispanohablantes.
하나의 언어. 하나의 목표. 100% 스페인어 화자를 위하여.

## Instrucciones para index.html
### 1. ¿Qué es este archivo?
Es el lugar donde el visitante aterriza por primera vez. No es una página para dar mucha información, sino nuestra "Tarjeta de Presentación Premium". Contiene nuestro imponente manifiesto de marca y actúa como el hub central que distribuye el tráfico hacia todas las subpáginas.
### 2. Reglas de Diseño y UX (La Sensación)
* Efecto "WOW" (Micro-interacciones): La primera impresión debe ser de extrema profesionalidad. Necesitamos un uso abundante de sutiles efectos de glow, fade-in, texturas y animaciones fluidas al hacer scroll.
* Menos Información, Más Impacto: No intentes enseñar ni explicar todo aquí. El objetivo es que el usuario piense: "¡Wow, esta página es increíblemente profesional!". Diseño y micro-interacciones vale más que el texto en esta página.
* Una Pantalla, Un Concepto: Si el contenido es largo, córtalo. Usa botones de (Ver más / Leer más) para enviar al usuario a las subpáginas.

(function () {
  var $$ = function (s, r) { return Array.prototype.slice.call((r || document).querySelectorAll(s)); };
  var RM = window.matchMedia && matchMedia("(prefers-reduced-motion:reduce)").matches;

  /* barra de progreso de scroll */
  var bar = document.getElementById("bar");
  function tick() {
    if (!bar) return;
    var max = document.documentElement.scrollHeight - innerHeight;
    bar.style.transform = "scaleX(" + (max > 0 ? scrollY / max : 0) + ")";
  }
  addEventListener("scroll", tick, { passive: true });
  addEventListener("resize", tick);
  tick();

  /* los h2 también se revelan (activa la línea naranja bajo el título) */
  $$("section h2").forEach(function (h) { h.classList.add("rv"); });

  /* revelado: al llegar al 20% del elemento aparece; --d escalona de arriba-izquierda a abajo-derecha */
  var els = $$(".rv");
  if (RM || !("IntersectionObserver" in window)) {
    els.forEach(function (el) { el.classList.add("in"); });
  } else {
    var io = new IntersectionObserver(function (entries) {
      entries.forEach(function (e) {
        if (!e.isIntersecting) return;
        e.target.classList.add("in");
        io.unobserve(e.target);
      });
    }, { threshold: 0.2 });
    els.forEach(function (el) { io.observe(el); });
  }

  /* foco de luz que sigue al cursor sobre las tarjetas de valores */
  var ticking = false, last = null;
  addEventListener("pointermove", function (ev) {
    last = ev;
    if (ticking) return;
    ticking = true;
    requestAnimationFrame(function () {
      var c = last.target.closest && last.target.closest(".cd");
      if (c) {
        var r = c.getBoundingClientRect();
        c.style.setProperty("--x", last.clientX - r.left + "px");
        c.style.setProperty("--y", last.clientY - r.top + "px");
      }
      ticking = false;
    });
  }, { passive: true });
})();

    // 초기 위치: 첫 번째 카드(인덱스 0, DESPEGUE)를 중앙에 세팅
    track.classList.add("is-spinning");
    track.scrollLeft = getCenterScroll(0);
    requestAnimationFrame(() => track.classList.remove("is-spinning"));

    // 2. 2초(2000ms) 동안 2바퀴(카드 8장분) 돌아 인덱스 8(3번째 세트 DESPEGUE)에 멈추는 함수
    let spun = false;
    const spinRoulette = () => {
      if (spun) return;
      spun = true;
      origCards.forEach(c => c.classList.add("in"));
      // 모션 감소 설정(접근성) 켜진 경우 회전 없이 즉시 중앙 정렬
      if (RM) {
        track.scrollLeft = getCenterScroll(setSize);
        return;
      }

      track.classList.add("is-spinning");

      const startX = getCenterScroll(0);          // 출발: 0번 (첫 세트 DESPEGUE)
      const targetX = getCenterScroll(setSize * 2); // 도착: 8번 (정확히 2바퀴 뒤 DESPEGUE)
      const distance = targetX - startX;
      const duration = 1500; // 요청하신 2초(2000ms) 여유 있는 회전
      const t0 = performance.now();

      // Quintic Out 곡선: 초반엔 휙휙 돌고 끝에서 부드럽고 묵직하게 감속
      const easeOutQuint = (t) => 1 - Math.pow(1 - t, 5);

      const step = (now) => {
        const elapsed = now - t0;
        const progress = Math.min(1, elapsed / duration);
        track.scrollLeft = startX + distance * easeOutQuint(progress);

        if (progress < 1) {
          requestAnimationFrame(step);
        } else {
          // 3. 정지 직후: 눈치채지 못하게 가운데 세트(인덱스 4, DESPEGUE)로 좌표를 치환해
          // 이후 사용자가 좌/우 어느 쪽으로든 화살표나 드래그를 할 수 있게 여유 공간 확보
          track.scrollLeft = getCenterScroll(setSize);
          track.classList.remove("is-spinning");
        }
      };

      requestAnimationFrame(step);
    };

    // 4. 화면 20% 지점 도달 감지 (threshold: 0.2)
    new IntersectionObserver(([entry], obs) => {
      if (entry.isIntersecting) {
        spinRoulette();
        obs.disconnect(); // 최초 1회만 실행
      }
    }, { threshold: 0.2 }).observe(track);

    // 5. 좌우 화살표 버튼(#peek-prev, #peek-next) 중앙 스냅 이동 연동
    const prevBtn = $("#peek-prev"), nextBtn = $("#peek-next");
    const stepWidth = () => origCards[0].offsetWidth + 24; // 카드 폭 + gap(24px)

    if (prevBtn) prevBtn.onclick = () => track.scrollBy({ left: -stepWidth(), behavior: "smooth" });
    if (nextBtn) nextBtn.onclick = () => track.scrollBy({ left: stepWidth(), behavior: "smooth" });
  })();

  /* ÚNETE: 듀얼 코어 카드 3D 틸트(기울기) & 홀로그램 반사광(Glare) 제어 */
  (() => {
    const card = $("#unete-card");
    if (!card || RM) return; // 모션 감소 환경에서는 고정

    let rafId = null;

    card.addEventListener("pointermove", (e) => {
      const rect = card.getBoundingClientRect();
      const x = e.clientX - rect.left; // 카드 내 마우스 X 좌표
      const y = e.clientY - rect.top;  // 카드 내 마우스 Y 좌표

      // 중심점(0.5, 0.5) 기준 -1 ~ +1 비율 계산
      const pctX = (x / rect.width) - 0.5;
      const pctY = (y / rect.height) - 0.5;

      if (!rafId) {
        rafId = requestAnimationFrame(() => {
          // 너무 과하지 않고 고급스러운 최대 ±5도 틸트
          card.style.setProperty("--rx", `${(-pctY * 8).toFixed(2)}deg`);
          card.style.setProperty("--ry", `${(pctX * 10).toFixed(2)}deg`);
          // 홀로그램 반사광 위치 업데이트
          card.style.setProperty("--gx", `${x}px`);
          card.style.setProperty("--gy", `${y}px`);
          rafId = null;
        });
      }
    }, { passive: true });

    // 마우스가 카드를 벗어나면 스르륵 원래 각도(0deg)로 복귀
    card.addEventListener("pointerleave", () => {
      card.style.setProperty("--rx", "0deg");
      card.style.setProperty("--ry", "0deg");
    });
  })();

});

(function () {
  const th = document.getElementById("th");
  if (!th) return;
  th.addEventListener("click", () => {
    const d = document.documentElement;
    const dark = d.dataset.theme ? d.dataset.theme === "dark" : matchMedia("(prefers-color-scheme:dark)").matches;
    d.dataset.theme = dark ? "light" : "dark";
  });
})();

(function () {
  const toggle = document.querySelector(".menu-toggle");
  const nav = document.getElementById("site-nav");
  if (!toggle || !nav) return;

  const label = toggle.querySelector(".visually-hidden");

  function setOpen(open) {
    toggle.setAttribute("aria-expanded", String(open));
    nav.classList.toggle("is-open", open);
    document.body.classList.toggle("nav-open", open);
    if (label) {
      label.textContent = open ? "Cerrar menú" : "Abrir menú";
    }
  }

  toggle.addEventListener("click", () => {
    setOpen(toggle.getAttribute("aria-expanded") !== "true");
  });

  nav.querySelectorAll("a").forEach((link) => {
    link.addEventListener("click", () => setOpen(false));
  });

  document.addEventListener("keydown", (event) => {
    if (event.key === "Escape") setOpen(false);
  });
})();
